# Character artwork

`sleep.svg`, `stretch.svg`, and `pet.svg` were authored directly as original vector paths by Codex / GPT-6 (exact variant unavailable) on 2026-10-12 for this repository. No copied assets, reference images, fonts, or third-party artwork were used. These are project artwork; no separate third-party license applies.

All poses use a 100 × 100 viewBox and display at 88 × 88 CSS px. The build optimizes copies using SVGO; source SVGs remain editable. Palette: ginger body, cream muzzle/belly, warm brown outlines, rose ears/cheeks. External image elements keep artwork separate from the popup DOM. Accessible descriptions live in `src/shared/cat-poses.ts`.
