# Roadmap

Order, not a promise of dates. Detailed state lives in TRACKING, current work in STATUS.

| Milestone | Scope | Exit gate |
| --- | --- | --- |
| M0 Foundation | DEV-001 | Resumable workspace; clean local Git checkpoint |
| M1 Feasibility | DEV-002, CAT-001 | Prototype toolchain validated; six consistent motions, small-size preview, and asset/node budgets checked |
| M2 Companion | EXT-001, CAT-002, UX-001 | Reliable permission/injection lifecycle, interactions, hide/restore |
| M3 Personalization/reminders | PER-001, REM-001 | Quiet defaults, customization, restart-safe reminder delivery |
| M4 Beta/release | QA-001 | No recurring annoyance or reliability issue; measured budgets; store materials |

Planning estimate: 5–7 weeks for one developer with artwork support; store review is additional. Validate estimates after M1. Create a new sprint plan only when its scope is chosen; avoid empty future sprint documents.
