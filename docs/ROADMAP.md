# Roadmap

Order, not a promise of dates. Detailed state lives in [TRACKING](TRACKING.md), current work in [STATUS](../STATUS.md).

The user-approved lean beta scope supersedes the earlier personalization/reminders-before-beta sequence and its 5–7 week estimate. No new delivery estimate is asserted.

| Milestone | Scope | Exit gate |
| --- | --- | --- |
| M0 Foundation | DEV-001 | Resumable workspace and local Git checkpoint |
| M1 Feasibility | DEV-002, CAT-001 | Validated toolchain and three expressive poses within budgets |
| M2 Core companion | EXT-001, UX-001 | Trial/site access, saved position, hide/pause, and permission lifecycle supported by verification evidence |
| M3 Focused polish | CAT-002, UX-002, UX-003 | Subtle blink/stretch, discreet accessible hide control, and clear setup/popup; no new feature suite |
| M4 Beta readiness | QA-001, REL-001 | Reliability/accessibility checks and measured performance acceptable; privacy/listing/demo/package ready |
| M5 Beta learning | BET-001 | 20–30 testers invited with consent; one/two-week feedback assessed before deciding further scope |

Current scoped work is [Sprint 005 — Lean beta polish](sprints/005-lean-beta-polish.md). Carry unresolved core verification into QA-001; do not equate a basic working report with complete release validation.

After beta, revisit REM-001, PER-001, CAT-003, EXT-002, or additional settings only if repeated feedback justifies them. A store submission or outreach campaign requires its own execution step; this roadmap does not claim either has occurred.
